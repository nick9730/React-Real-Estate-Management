React-Real-Estate-Management I built one appliaction with Vite+React+Typescript and Tailwind.

This site contains:

    Animation from framer-motion,
    Routers from React-Router-Dom,
    Fetching data from supabase,
    zod for the form-validation
    Usage of React-Query,
    Pagination by React-Query,
    Google Maps Api

Developed a high-performance property management platform using Vite, React, and TypeScript.

Implemented complex state management and server state synchronisation using React Query (TanStack Query) for efficient data fetching and pagination.

Integrated Supabase for back-end services, handling database operations and real-time data updates.

Built dynamic search and filtering functionality using URL search parameters (setSearchParams), allowing users to share filtered results via links.

Integrated Google Maps API for interactive property location visualisations.

Ensured data integrity and robust user input handling with Zod for form validation and Framer Motion for smooth UI animations.

Styled with Tailwind CSS focusing on a responsive and modern user interface.
